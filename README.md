# User Profile Card Generator

## Project Overview
The User Profile Card Generator is a Flask-based web application that allows users to generate a profile card by entering details such as name, bio, and image URL. The application processes user input through a form and dynamically displays a formatted profile card.

---

##  Features
- User-friendly form interface
- Accepts Name, Bio, and Image URL
- Generates dynamic profile cards
- Responsive and clean design
- Backend integration using Flask

---

##Technologies Used
- Python
- Flask
- HTML
- CSS
